# SHADOW TRACKER 4.0
Native Android starter project using Kotlin and Jetpack Compose.

Included: purple/dark System-style interface, local missions and XP, notes, simple offline rule-based assistant, AES-GCM encryption utility scaffold, sync interface placeholder, example ciphertext-only Supabase schema, GitHub Actions debug-APK workflow.

Not yet implemented: real generative AI, cloud sync, account login, QR pairing, biometric lock, voice, image/document understanding, conflict resolution, production key recovery, release signing. This is a starter scaffold, not a finished production app.

## Build
Open the folder in Android Studio, allow Gradle sync, then Build > Build APK(s). Debug APK output: app/build/outputs/apk/debug/app-debug.apk.
